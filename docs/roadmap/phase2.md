# Phase 2 Roadmap — Post-MVP

Reserved workflows. **Not in MVP scope.** Names are hueCraft-owned.

## PlateLay — flat / double-sided printing

- Face-down orientation for glossy top surface
- Double-sided alignment guides
- Requires multi-material auto-swap hardware

## StackNest — height reduction

- Detect repeated filament in vertical stack
- Nest mesh segments to reduce total Z height
- Only when blend direction compatible

## PlateTile — multi-plate tiling

- Split large art across build plates
- Registration marks per plate
- Export plate bundle

## TD Link — hardware integration

- Optional serial/WebSerial TD measurement devices
- Import reading into filament library

## Filament Commons

- Signed community filament pack format
- Attribution + verification hash
- No import of proprietary competitor libraries

## Entry criteria for each

- MVP optics validation pass rate ≥ 80% on golden fixtures
- Core workbench stable 4 weeks
- User demand signal from issues/discussions
